# deploy.oci.md — OCI VM (ACTIVE deploy target)

**Status: ACTIVE** — skale.dev runs here. Agents: this is the sidefile to read
before touching server config or the deploy flow.

## Infrastructure

- OCI VM, SSH alias **`amd2`** (`~/.ssh/config` → amd2.skale.dev, user `ubuntu`, key `~/.ssh/oci`).
- **nginx** serves the static Astro build from **`/var/www/skale.dev`**.
- Site config: `/etc/nginx/sites-enabled/*skale*`. Catch-all: `location / { try_files $uri $uri/ =404; }`.

## Deploy flow

```bash
./scripts/deploy-skale.sh --build
```

1. Guards: dirty-tree abort · `dist/firmenindex` abort · stale-dist abort (source newer than build).
2. `astro build` (direct call — runs the `skillsStatic` integration, see below).
3. rsync `dist/` → `amd2:/var/www/skale.dev` (**overlay sync, no `--delete`** — stale files never die automatically).
4. Post-deploy smoke: md5 of `https://skale.dev/` vs local `dist/index.html`, exit 1 on mismatch.

Target/path config lives in `deploy.config` (gitignored): `DEPLOY_HOST`, `DEPLOY_REMOTE_DIR`, `DEPLOY_DIST`.

## Skills endpoints on this host

- `/s/<slug>` = **static files** `dist/s/<slug>`, generated by the `skillsStatic`
  Astro integration on every build (source of truth: the recommended-skills blog
  frontmatter; template in `scripts/skills-lib.mjs`). nginx serves them via plain
  `try_files` — no runtime backend.
- `dist/s/available` lists the visible slugs (hidden ones like `gakefay` stay installable but unlisted).

## firmenindex separation (incident 2026-09-10)

- The firmenindex app has its OWN webroot **`/var/www/firmenindex`** + nginx `location ^~ /firmenindex/`
  + own deploy from the **firmenbuch_AT** repo. THIS deploy must never contain firmenindex files
  (the script aborts if `dist/firmenindex` exists). skale.dev only links to it.
- `/firmenindex/api` is the one live API: nginx proxy → `127.0.0.1:8099`.
